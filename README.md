## ✨ Features

- **Strategic Positioning** — Target audience, brand tone, and key differentiators
- **Interactive Charts** — Audience segmentation (Doughnut) and competitive radar (Chart.js)
- **Visual Moodboard** — Premium packaging, texture photography, and scientific terroir
- **Content Pillars** — 4 provocative content angles with ready-to-use captions
- **Scroll Animations** — Smooth reveal-on-scroll effects
- **Responsive Design** — Fully responsive across all devices

## 🛠 Tech Stack

- HTML5 + Tailwind CSS (CDN)
- Chart.js for interactive data visualization
- Google Fonts (Playfair Display + Inter)
